# Production Checklist
## VEDRA – A Founder's Promise

### Assets
- [ ] All video files imported and labeled correctly
- [ ] All image files imported and labeled correctly
- [ ] Audio files (if any) imported and labeled

### Voice-over
- [ ] Record voice-over using the provided script
- [ ] Edit and clean audio (remove noise, adjust levels)
- [ ] Synchronize voice-over with visual timeline

### Music
- [ ] Select appropriate background track
- [ ] Edit music to fit scene transitions and pacing
- [ ] Mix music with voice-over and sound effects

### Colour Grading
- [ ] Apply consistent color grade across all scenes
- [ ] Ensure visual tone matches the mood of each scene
- [ ] Check for color continuity between shots

### Sound Design
- [ ] Add ambient sounds where appropriate (e.g., keyboard typing, city hum)
- [ ] Add impact sounds for transitions and key moments
- [ ] Ensure audio levels are balanced and not overwhelming

### Logo Animation
- [ ] Create or import VEDRA logo animation
- [ ] Place logo animation at the end of the timeline
- [ ] Animate logo with appropriate timing and effects

### Export
- [ ] Set export settings to desired resolution and format
- [ ] Export a preview for internal review
- [ ] Export final version for distribution

- [ ] v0.3: Final adjustments
